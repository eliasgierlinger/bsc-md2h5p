# Multiple choice

A question with several right answers:

```multiplechoice
What are cool animals?
*Dogs
*Cats
Birds
```

And one with exactly one right answer, which is still drawn as checkboxes because
`behaviour.type` is pinned to `multi` - the widget follows the syntax the author wrote, not
the number of stars:

```multiplechoice
Which of these is a bird?
Dog
*Owl
Cat
```
